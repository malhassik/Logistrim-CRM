# Logistrim CRM (Внутренняя система транспортной компании)

Учебный проект, представляющий собой внутреннюю CRM-систему (ERP) для управления автопарком небольшой транспортной компании. Проект разработан для автоматизации учета машин, водителей, документов (ТН) и расхода топлива.

## 🚀 Функционал
- **Авторизация и роли:** Доступ к системе закрыт. Разграничение прав (Администратор видит всё, Бухгалтер может только просматривать автопарк и загружать документы).
- **Учет автопарка:** Добавление машин (госномер, марка, пробег) и автоматическое назначение статуса при закреплении водителя.
- **Учет водителей:** Связь водителя с конкретной машиной (ForeignKey).
- **Документооборот (ТН, чеки):** Загрузка файлов (PDF, изображения) прямо через сайт и привязка их к машинам.
- **Учет топлива:** Ведение журнала заправок (литры, стоимость) с автоматическим подсчетом общих расходов на дашборде.
- **Дашборд:** Наглядная статистика на главной странице (всего машин, свободные машины, количество документов, суммарные расходы на топливо).

## 🛠 Технологии
- **Python 3.14**
- **Django 6.0** (фреймворк)
- **SQLite** (база данных для разработки)
- **HTML/CSS** (интерфейс в темной теме)
- **Git** (контроль версий)

## 📂 Структура базы данных (Модели)
1. `Truck` (Машина) — связана с `Driver` и `Document`.
2. `Driver` (Водитель).
3. `Document` (Документы) — хранит загруженные файлы.
4. `FuelRecord` (Заправки) — хранит историю расходов на топливо.
