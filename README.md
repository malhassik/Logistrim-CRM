# Logistrim CRM (Внутренняя система транспортной компании)

Учебный проект, представляющий собой полноценную внутреннюю CRM-систему (ERP) для управления автопарком небольшой транспортной компании. Проект разработан для автоматизации учета машин, водителей, документов (ТН) и расхода топлива.

## 🚀 Функционал
- **Авторизация и роли:** Закрытый доступ. Разграничение прав (Администратор видит всё, Бухгалтер — только просматривает автопарк, добавляет документы и заправки).
- **Учет автопарка:** Добавление машин, водителей. Автоматическое назначение статуса «Занята» при закреплении водителя.
- **Документооборот (ТН, чеки):** Множественная загрузка файлов (PDF, изображения) прямо через сайт с привязкой к конкретной машине.
- **Учет топлива:** Ведение журнала заправок с валидацией и автоматическим подсчетом общих расходов на дашборде.
- **Дашборд:** Наглядная статистика (всего машин, свободные машины, количество документов, суммарные расходы на топливо).
- **Живой поиск:** Мгновенная фильтрация таблицы машин по номеру или марке (JavaScript).
- **AJAX:** Отправка форм (например, добавление заправки) без перезагрузки страницы с выводом всплывающих уведомлений.
- **REST API:** Полноценный API для интеграции с мобильными приложениями (CRUD для машин с правами доступа).

## 🛠 Технологии
- **Backend:** Python 3.12, Django 6.1, Django REST Framework (DRF).
- **База данных:** PostgreSQL (в Docker), SQLite (локальная разработка).
- **Инфраструктура:** Docker, Docker Compose, Gunicorn, WhiteNoise.
- **Frontend:** HTML5, CSS3 (адаптив, темная тема), JavaScript (DOM, Fetch API, AJAX).
- **Архитектура:** MVT (Model-View-Template), ORM, ООП.

## 📂 Структура проекта
- `fleet/` — основное приложение (модели, вьюхи, формы, API, шаблоны).
  - `models.py` — модели `Truck`, `Driver`, `Document`, `FuelRecord`.
  - `views.py` — логика страниц и API.
  - `serializers.py` — сериализаторы DRF для преобразования объектов в JSON.
  - `urls.py` — маршрутизация приложения.
- `logistrim/` — настройки проекта (`settings.py`, главный `urls.py`).
- `Dockerfile` — инструкция сборки контейнера.
- `docker-compose.yml` — конфигурация взаимодействия Django и PostgreSQL.
